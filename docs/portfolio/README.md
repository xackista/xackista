## How to evaluate the work

For each capability, look for four things:

- Architecture — can the engineer explain dependencies?
- Implementation — is there concrete code/configuration?
- Troubleshooting — is there a safe diagnostic method?
- Validation — is there evidence that the result works?

The portfolio follows that model throughout.
