# Portfolio Evidence Matrix

| Capability | Evidence in repository | Client takeaway |
|---|---|---|
| Linux administration | Troubleshooting runbooks + case studies | Can investigate real server incidents systematically |
| RHEL security | Security role + validation | Can harden and verify Linux hosts |
| Kubernetes | HA architecture + manifests + troubleshooting | Can operate workloads and diagnose failures |
| OpenShift | VMware UPI architecture + troubleshooting | Understands enterprise platform deployment |
| VMware | HA/DRS/SAN architecture | Understands compute, HA and storage dependencies |
| Ansible | Reusable Linux baseline role | Can turn procedures into repeatable automation |
| Terraform | Reusable metadata/module structure | Understands infrastructure-as-code patterns |
| Monitoring | Prometheus alerts + evidence guide | Can turn metrics into actionable operations |
| Ceph | CSI troubleshooting scenarios | Understands Kubernetes persistent storage failures |
| Backup | Backup troubleshooting case study | Can separate control/data paths and isolate failures |

## Evidence levels

**Level 1 — Documentation:** Architecture, commands and reasoning.

**Level 2 — Code:** Reusable manifests, automation and configuration.

**Level 3 — Lab evidence:** Screenshots, command output and test results captured from a real lab.

**Level 4 — Verified client evidence:** Only where disclosure is explicitly permitted.

This repository intentionally does not pretend Level 3 or Level 4 evidence exists when it has not been captured.
